How to Use These Components

1. Copy the Component Code

Each component is self-contained. Simply copy the entire <klint> element including its embedded script.

2. Customize Attributes

Modify the data attributes to customize the component's appearance and behavior.

3. Add Interactivity

// Example: Making the toggle switch interactive
const toggle = document.getElementById('toggle1');
toggle.addEventListener('click', () => {
    const isChecked = toggle.getAttribute('data-checked') === 'true';
    toggle.setAttribute('data-checked', !isChecked);
});

4. Create Component Functions

// Example: Factory function for creating loaders
function createLoader(type, color) {
    const loader = document.createElement('klint');
    loader.setAttribute('width', '100');
    loader.setAttribute('height', '100');
    loader.setAttribute('data-type', type);
    loader.setAttribute('data-color', color);
