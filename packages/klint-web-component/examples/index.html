Klint Web Component Examples

A collection of examples demonstrating the Klint canvas library as a web component

Key Features

  • ✨ Full compatibility with Klint drawing API
  • 🎨 All Element classes (Color, Vector, Easing, etc.)
  • 🎬 Animation loop with configurable FPS
  • 📐 Automatic resize handling
  • 👁️ Intersection Observer for visibility
  • 🖼️ Static mode for generating images
  • 📱 Responsive and DPR-aware
  • 🎯 Custom events and callbacks
  • 🚀 Offscreen canvas support
  • 🔧 Both declarative and programmatic APIs

Quick Start

<!-- Import the web component -->
<script type="module">
    import './klint-canvas.js';
</script>

<!-- Declarative usage with inline script -->
<klint width="400" height="400" fps="60">
    <script type="text/klint">
        function setup(ctx) {
            ctx.background('#000');
        }
        
        function draw(ctx) {
            ctx.fillColor('#fff');
            ctx.circle(ctx.width/2, ctx.height/2, 50);
        }
    </script>
</klint>

Programmatic Usage

const canvas = document.querySelector('klint');

// Assign callback functions
canvas.setup = (ctx) => {
    console.log('Canvas initialized!');
};

canvas.draw = (ctx) => {
    ctx.background('#000');
    ctx.fillColor('#fff');
    ctx.circle(ctx.time * 100, ctx.height/2, 30);
};

// Listen to events
canvas.addEventListener('klint-ready', (e) => {
    console.log('Context:', e.detail.context);
});

// Control playback
canvas.play();
canvas.pause();
canvas.saveCanvas();

Attributes

  • width - Canvas width in pixels
  • height - Canvas height in pixels
  • fps - Frames per second (default: 60)
  • dpr - Device pixel ratio (default: "default")
  • origin - Canvas origin: "corner" or "center"
  • alpha - Enable alpha channel (default: "true")
  • noloop - Disable animation loop
  • static - Generate static image
  • ignoreResize - Disable resize handling
